# CSS Pizza

Learning exercise for **CSS positioning & visual composition**

## 🎯 Objective

**Main goal**: Create a recognizable pizza using only HTML and CSS, focusing on element positioning techniques to achieve a realistic visual result.

**Context**: This exercise emphasizes CSS positioning strategies and creative use of CSS properties to draw shapes and compose a complete illustration. The MVP requires the pizza to be instantly recognizable at first glance.

## 🧠 Key Learnings

- **Technical concept mastered**: CSS positioning to create and arrange visual elements

## 🛠 Tech Used

- HTML5
- CSS3 (Positioning, Transform, Border-radius)
- CSS Custom Properties (Variables)
